# Homebrew Tap

Homebrew casks for Martin Rusetski's macOS apps.

## Installation

Add the tap once using the shorter `mrtnby/tap` alias:

```sh
brew tap mrtnby/tap https://github.com/martinrusetski/homebrew-tap
brew trust mrtnby/tap
```

Then install either app:

```sh
brew install --cask mrtnby/tap/rom-shortcut-maker
brew install --cask mrtnby/tap/true-tone-manager
```

## Available apps

- [Rom Shortcut Maker](https://github.com/martinrusetski/rom-shortcut-maker) - generate native launchers for ROM libraries.
- [TrueTone Manager](https://github.com/martinrusetski/true-tone-manager) - automatically control True Tone for individual apps.
